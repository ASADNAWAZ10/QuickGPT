# 🚀 QuickGPT

QuickGPT is a full-stack AI-powered chatbot application built using the MERN Stack. The application provides users with an interactive chat interface to communicate with an AI assistant, generate responses in real time, and enjoy a seamless user experience through a modern and responsive design.

## ✨ Features

* 🤖 AI-Powered Chatbot
* 🔐 User Authentication & Authorization
* 💬 Real-Time Conversations
* 📜 Chat History Management
* 📱 Responsive Design for All Devices
* ⚡ Fast and Optimized Performance
* 🎨 Modern UI with Tailwind CSS
*     Light & dark theme
* 🔒 Secure Backend APIs
* 🌐 RESTful API Architecture

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Axios
* React Router DOM

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Authentication

* JWT (JSON Web Token)

### Version Control

* Git & GitHub

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/ASADNAWAZ10/QuickGPT.git
```

### Navigate to Project Directory

```bash
cd QuickGPT
```

### Install Frontend Dependencies

```bash
cd client
npm install
```

### Install Backend Dependencies

```bash
cd ../server
npm install
```

## ▶️ Running the Application

### Start Backend

```bash
npm run server
```

### Start Frontend

```bash
npm run dev
```

The application will be available at:

```bash
http://localhost:5173
```
